04 / The Edit

Content vs. Code

It is important to distinguish between updating information and altering the digital structure.

Content
You → Sanity

Update hero imagery, hero videos, website copy, team members, and projects directly.

Code
Lune → GitHub

Adding entirely new pages, creating new layouts, or altering the digital structure.

You will only need to contact Lune if you want to add new pages or change the layout altogether.
